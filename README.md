# Мини CRM

Простая CRM-таблица клиентов с **серверным хранением данных** (Vercel + Vercel KV).
Данные видны с любого устройства и не зависят от браузера. Отдельная регистрация в сторонних сервисах не нужна — всё делается внутри Vercel.

## Возможности
- Таблица клиентов: имя, телефон, email, статус (Новый / Активный / Закрытый), примечание
- Добавление / редактирование / удаление через модальное окно
- Поиск, сортировка по колонкам, счётчики статистики
- Экспорт в CSV
- Хранение на сервере (Vercel KV) — данные общие для всех устройств

## Структура
```
index.html      — интерфейс
style.css       — стили
app.js          — логика (работает через fetch с /api/clients)
api/clients.js  — серверная функция Vercel (REST API + Vercel KV)
package.json    — зависимости (@upstash/redis)
vercel.json     — конфиг деплоя
```

## Деплой (один раз, ~3 минуты)
1. https://vercel.com → Add New Project → импортируйте этот репозиторий → **Deploy**.
2. В дашборде проекта: **Storage → Create Database → KV → Create** (бесплатный тариф).
   Переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` добавятся в проект автоматически.
3. **Project → Settings → Deployments → Redeploy** (чтобы лямбды увидели новые переменные).

Готово: приложение работает по адресу вида `mini-crm.vercel.app`, данные хранятся на хостинге.
Каждый push в main — автоматический передеплой.

## Локальный запуск
```bash
npm i -g vercel
vercel link && vercel dev   # поднимет и статику, и /api/clients
```
Локальные переменные окружения возьмутся из `.env.local`:
```
KV_REST_API_URL=...
KV_REST_API_TOKEN=...
```
(или выполните `vercel env pull .env.local`)
