# Мини CRM — список клиентов

Простое клиентское приложение (без сервера и сборки): таблица клиентов с поиском, сортировкой, статусами и экспортом в CSV. Данные хранятся в браузере (localStorage).

## Возможности
- ➕ Добавление / ✏️ редактирование / 🗑 удаление клиентов
- 🔍 Мгновенный поиск по имени, телефону, email, примечанию
- ⇅ Сортировка по колонкам
- 🏷 Статусы: Новый / Активный / Закрытый + счётчики
- 📄 Экспорт в CSV (совместим с Excel, разделитель `;`, UTF-BOM)
- 📱 Адаптивная вёрстка

## Локальный запуск
Просто открой `index.html` в браузере, либо:
```bash
npx serve .
```

## Деплой на Vercel
1. Залей этот репозиторий на GitHub.
2. На [vercel.com](https://vercel.com) → **Add New Project** → выбери репозиторий.
3. Фреймворк: *Other*, Build command: оставить пустым, Output directory: `.` (в `vercel.json` уже настроена статическая раздача).
4. Нажми **Deploy** — через минуту сайт готов.

Альтернатива через CLI:
```bash
npm i -g vercel
vercel --yes
```

Другие бесплатные варианты хостинга: GitHub Pages, Netlify, Cloudflare Pages — для этого проекта они подходят так же хорошо (это чистый статический HTML/CSS/JS).

## Важно
localStorage привязан к браузеру: данные не синхронизируются между устройствами. Если нужна общая база для нескольких пользователей — потребуется бэкенд (например, Supabase/Firebase), могу добавить.
