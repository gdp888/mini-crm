# Мини CRM

Простая таблица клиентов: поиск, сортировка, статусы, экспорт в CSV.
Данные хранятся на сервере (Vercel Blob), доступны с любого устройства.

## Деплой на Vercel (всё в одном месте, ~3 минуты)

1. vercel.com → **Add New Project** → импортируй этот репозиторий → **Deploy**.
2. В дашборде проекта: **Storage** → в разделе «Blob storage» (он есть в списке сразу) → **Create** → выбери свой проект → **Connect**.
   Отдельная регистрация не нужна — Blob создаётся прямо внутри Vercel, переменная `BLOB_READ_WRITE_TOKEN` добавляется автоматически.
3. **Settings → Deployments → Redeploy** последнего деплоя (чтобы функции подхватили переменную окружения).

Готово. Проверить подключение можно открыв `<твой-сайт>/api/status` — должно быть `"blobToken": "SET"` и `"readTest": {"ok": true}`.

Каждый push в `main` — автоматический передеплой.

## Локальная разработка

Просто открой `index.html` в браузере — без сервера приложение работает на localStorage.
Для работы с серверной базой локально: `npm i`, скопируй `BLOB_READ_WRITE_TOKEN` из дашборда Vercel в `.env.local` и запускай через `npx vercel dev`.

## Структура

- `index.html`, `style.css`, `app.js` — фронтенд (без сборки)
- `api/clients.js` — CRUD-эндпоинт (GET/POST/PUT/DELETE)
- `api/_db.js` — доступ к хранилищу (Vercel Blob)
- `api/status.js` — диагностика подключения
